# University HR RAG Assistant

A Retrieval-Augmented Generation (RAG) based HR knowledge assistant for university employees.

## Purpose

The system allows employees to ask questions about university HR policies, procedures, workplace ethics, leave policies, salary increments, employee responsibilities, and other HR-related information.

## Core Approach

The application uses Retrieval-Augmented Generation (RAG) to retrieve relevant information from approved university HR documents before generating an answer.
